# Security Policy

This project follows the **XHToken Community Security Policy**.

The full text is maintained in the community repository:

👉 **[XHToken Security Policy](https://github.com/XHToken/community/blob/main/SECURITY.md)**

## Reporting a Vulnerability

**Do not** report security vulnerabilities through public GitHub issues.

Please report vulnerabilities privately via [GitHub Security Advisory](https://github.com/XHToken/community/security/advisories/new) or email the security team at tokenspark-security@googlegroups.com.
